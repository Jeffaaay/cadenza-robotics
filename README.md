# Cadenza Robotics

基于 OpenArm 的机器人系统工程与遥操作研究项目。先复现可运行的平台，弄清已有方法能做什么、在哪些条件下失败，再改进算法或控制并做同条件对照。

当前阶段：资料与搭建规划。实体库存、采购预算和实机运行尚未确认，没有本项目的实机性能结果。

## 已确定的范围

- 初期复用 OpenArm 的承力结构、关节布局、传动和原装夹爪。OpenArm 2.0.0 是当前资料基准；实际制造前还要核对选定硬件与 CAD、BOM、固件、模型的一致性。
- 先按单臂整理和验收，双臂作为后续扩展。单臂与左右侧的选择还不是采购决定。
- 开发自己的非承力、可拆卸外壳，形成 Cadenza 的外观。保留裸机基准，安装外壳后重新测量重量、温升、运动范围和跟踪误差。
- 五指手、指尖改造与钢琴演奏保留为未来方向，目前选型和制作暂停。此前人民币 3,000–7,000 元是单只灵巧手的零件预算，不是 OpenArm 总预算。
- 论文目标建立在可复现的测量与明确改进上。平台复刻、换名字或换壳是工程成果，本身不代表已形成论文贡献。

## 工作路线

| 阶段 | 要完成的事 | 完成的依据 | 当前状态 |
|---|---|---|---|
| 0 资料与版本 | 核对来源、现有资产、库存和费用范围 | 可追溯版本、分项清单、库存与报价 | 资料已整理；库存与报价待核实 |
| 1 实体平台 | 装配原结构、接线、标定、基础运动和夹爪控制 | 装配记录、标定值、实际状态日志；断电和通信中断行为已验证 | 未开始实机验证 |
| 2 复现基准 | 复现一种已有遥操作方法，完成规定任务并录制数据 | 相同条件的重复试验，保留成功、失败和操作视频 | 未执行 |
| 3 改进控制或算法 | 从高频失败中选一个问题，核查文献后修改 | 对比原基准、消融与重复实验，说明有效范围和代价 | 等待基准失败记录 |
| 4 外壳集成 | 完成可拆外壳，复测同一基准 | 无干涉、散热和维修检查；性能变化有记录 | 范围已定，未设计制造 |
| 5 扩展 | 根据需求决定双臂、五指手或弹琴 | 各自的硬件可行性和任务评估 | 待定 |

外壳的风格与分件设计可以和平台搭建并行；安装后的性能应与同一硬件的裸机配置比较。算法研究不依赖先完成外壳。

原始 CAD、论文 PDF、视频、虚拟环境和历史演示不重复塞入本仓库。实际开发产生的配置、代码、实验记录和原创外壳设计按用途加入，不先创建空目录。

## 上游与研究笔记

本项目复用 Enactic 的 [OpenArm](https://github.com/enactic/openarm) 平台。当前承力机械结构来自 OpenArm；Cadenza 是我们的集成、外观与研究项目名称，不代表重新发明了机械臂。

- [OpenArm 硬件 2.0.0](https://github.com/enactic/openarm_hardware/releases/tag/2.0.0)：上游硬件标注 CERN-OHL-S-2.0。
- [官方文档](https://docs.openarm.dev/)与[遥操作](https://docs.openarm.dev/teleop/)：具体运行版本需与硬件一起核对。
- [研究笔记仓库](https://github.com/Jeffaaay/robotics-research-notes)：论文正文、PDF、图片和视频入口继续集中在各论文文件夹。本仓库只链接相关分析，不复制一套笔记。

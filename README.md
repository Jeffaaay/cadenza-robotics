# Cadenza Robotics

基于 OpenArm 的机器人系统工程与操作学习研究项目。第一阶段目标是：**双臂 OpenArm＋夹爪，在固定桌面上自主叠 T 恤。** 先复现已有能力，记录失败，再改进控制或学习方法。

当前阶段：资料与搭建规划。已核对两个邮箱和部分任务历史，找到 RTX 4060 Ti 16GB 台式机、Jetson J4012、P1S、D405、CANable 和开发板的订单/送达证据，详见 [设备盘点](BUILD.md)。设备当前可调拨状态、OpenArm 本体、整个平台预算与桌面布局仍待确认，没有本项目的实机性能结果。

## 已确定的范围

- 首版按 Hugging Face / LeRobot 的叠衣参考系统对齐：两条 OpenArm 执行臂、作者公开的上臂加长 5 cm 改件与夹爪接触件、一对 OpenArm Mini 示教器、三路 RGB 相机。先复用已有电机和设备，打印件按装配需要单独安排。
- 按左、右两条执行臂规划完整平台；装配与调试仍逐臂进行，再验证双臂协同。双臂是当前任务所需配置，不是后续可选扩展，也不代表已决定采购。
- OpenArm 2.0.0 是本地已有的 CAD/BOM 对照资料，尚未确认是作者实验所用硬件版本。整套方案已选定，但准确电机修订、改件安装接口、布局和制造规格仍需核对，不能把两套资料直接混成采购清单。
- 先建立参考配置的基准，再开发自己的非承力、可拆卸外壳。安装外壳后重新测量重量、温升、运动范围和跟踪误差。
- 五指手、指尖改造与钢琴演奏保留为未来方向，目前选型和制作暂停。此前人民币 3,000–7,000 元是单只灵巧手的零件预算，不是 OpenArm 总预算。
- 论文目标建立在可复现的测量与明确改进上。平台复刻、换名字或换壳是工程成果，本身不代表已形成论文贡献。

## 工作路线

| 阶段 | 要完成的事 | 完成的依据 | 当前状态 |
|---|---|---|---|
| 0 资料与布局 | 对齐叠衣参考配置，核对现有电机及改件接口 | 匹配版本的分项清单；桌面、双臂、衣物和相机布局 | 整套方案已选；电机实物、基体版本、制造规格和布局待核对 |
| 1 实体平台 | 每臂装配、标定、夹爪与基础运动，再进行双臂检查 | 实际状态日志、可达性和干涉记录；停止与恢复行为已验证 | 未开始实机验证 |
| 2 示教与采集 | 抓放、夹住布角、双臂整理；录制三视角与状态/动作 | 可重复遥操作任务，数据同步、顺序、单位正确 | 未执行 |
| 3 铺平 T 恤折叠 | 适配公开模型，完成受限场景的自主折叠 | 独立试验中记录成功率、质量、时间和所有人工干预 | 未下载权重或运行策略 |
| 4 揉乱 T 恤整理 | 展开、折好、放到指定区域 | 与铺平任务分开计分；分类记录抓空、滑落、展开失败 | 待铺平任务基准 |
| 5 研究改进 | 优先观察失败恢复，再决定低数据适配或双臂柔顺控制 | 原基准、消融、相同干预预算和留出条件 | 候选问题，未确认新颖性 |
| 基准后 外壳 | 完成可拆外壳，复测同一任务 | 质量、干涉、散热、视野和维护记录 | 未设计制造 |

先让参考配置可运行，再改变外观；安装后的性能与同一硬件的裸机配置比较。算法研究不依赖先完成外壳。

## 从哪里开始

- [搭建与外壳范围](BUILD.md)：双臂分项清单、示教器、相机、复现差异与装配顺序。
- [基准与研究方法](BASELINES.md)：从抓放到自主叠衣的验收、数据接口和研究对照。
- [上游版本记录](upstreams.lock.json)：已检查的源码提交、发布包与本地文件哈希。记录来源不等于这些版本已完成联合兼容测试。

下一项具体工作是把用户现有电机的型号、减速比、电压和数量对应到执行臂或 Mini 示教器，再核对参考硬件版本与改件接口。计算机与打印机优先复用；D405 留作台架测试，参考策略的相机先按原方案匹配，CANable 验证后才能抵扣通信缺口。预算、桌面尺寸和供货配置补齐后形成差额报价，尚不下单或开印。

接近作者硬件可以减少适配差异，但不保证原权重即插即用。例如臂长不同，同一个关节角度会把夹爪带到不同位置；即使臂长相同，相机位置、零点和控制时序仍影响模型。公开权重先做离线接口与推理检查，经过基础实机验收后才进入自主执行。

直接参考的技术报告、图片和视频集中在[Unfolding Robotics 阅读笔记](https://github.com/Jeffaaay/robotics-research-notes/tree/main/unfolding-robotics)。该报告是作者公开的工程实验，不标成已确认同行评审论文。Sunday Memo 作为完整家用系统的对照，不作为 OpenArm 的同款硬件或可直接部署的软件。

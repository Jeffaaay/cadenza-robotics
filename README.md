# Cadenza Robotics

基于 OpenArm 的双臂家用机器人与操作学习研究项目。当前目标是**沿用已购电机，用 P1S 和普通 PLA 尽量制作全部定制结构，第一阶段只做可靠固定的双臂上半身，暂不做下半身**，面向叠衣、物品分类/整理等轻载任务。外形希望细窄，不能通过额外外移肩轴来解决所有装配问题。

用户在美国难以取得定制金属件，因此默认制造路线从“购买金属加工结构”调整为 **PLA 优先重设计**。已有电机、轴承、螺栓及必要标准轴/套筒仍按功能使用；这不是已经证明整机可以全 PLA，也不是把原金属 CAD 原尺寸直接打印。材料依据、真实 CAD 视图及 34 组逐件路线见 [轻载材料评估](design/material-review/README.md)。

既有个人研究主线 **Fault Injection：抽象动作噪声能否预测模仿学习策略在真实硬件故障下的表现与失败模式？** 保留。VLA 与用户所称“NCT”是应用方向；NCT 含义未确认，不替换成 ACT。硬件双臂目标与首轮研究可选单臂任务分开管理，具体任务、策略、首故障及投稿目标尚未冻结。

状态更新（2026-11-19）：用户确认主臂电机已购、没有随箱线材；具体型号、数量、修订仍需实物盘点。P1S 已收到，无 AMS。Mini 文件准备和本次 CAD/静态计算均不是已打印、已装配或实机验收。新 PLA 承力件尚无可制造 CAD 和实测性能。

## 已确定的范围

- 双臂 OpenArm＋两只夹爪，参考共 14 个臂关节＋2 个夹爪驱动；逐侧装配/联调，最终验证双臂公共工作区。参考 BOM 不替代实际收货记录，不据它更换已购电机。
- 第一阶段为固定上半身：双臂、肩部支承、必要的短躯干和相机，可靠连接到工作台/固定支架；优先跑通 VLA 与其他学习模型的实验。轮架、轮组、移动电池和下半身移到后续，不作为本阶段前置条件；双臂目标保持。
- 自行装配，定制结构默认优先 PLA，尽量不依赖 CNC/钣金；轴承、螺栓、标准轴/销/套筒等现成件按需保留。特殊轴及打印精密接口仍有待解决项，不承诺零金属或零加工。
- 允许重新设计主承力件并调整截面、连接和分件；保留原版几何/惯量作对照，记录轴线、质量、限位和控制参数变化。原结构不等比例缩小，不沿用旧概念额外外移 85 mm/侧的肩位。
- 先做接口试片和 J6_A/B/C 闭合梁试件，验证后推进 J4_D/E、J4_A 及肩/腕/固定上半身；轮架后续再做。外罩与承力件分别验收；全 PLA 可行性和最终负载范围尚未证实。
- 复用现有电脑、Jetson、P1S、D405 和通信设备。Mini 仍是示教输入候选；两条参考 Mini 共需 16 个小舵机，已记录的 12 个 SER0069 数量不足完整双套，减速比和回驱兼容性也未验证。
- 五指手、钢琴和腿暂缓；参考上臂 +5 cm、三视角和公开 folding_final 不是当前打印结构的直接制造指令。是否采用取决于任务、兼容性和验证。
- 研究先比较同一策略的抽象噪声与有依据故障；平台复刻、换壳及结构打印是工程成果，本身不代表已形成论文贡献。

## 第一阶段：固定上半身与模型实验

当前可行性判断：PLA 为主的固定上半身值得做低负载原型；所有定制承力件都能满足要求尚未证实。原金属几何直接换成同尺寸 PLA 不属于已验证方案。肩根、轴承座、夹爪轴/轮毂及电机附近的热态连接是优先验证点；可能需要较大的截面或局部标准件加强。

1. **模型离线跑通（已完成首轮）**：2026-11-19 在当前 RTX 5060 Laptop 8 GB 主机上，以公开记录分别运行 OpenArm SmolVLA 单臂策略和 ACT 双臂策略，检查完整动作块、显存与推理时间。代码、固定版本、全部尝试及复现命令见 [离线实验](experiments/offline-inference/README.md)。未连接电机，未测任务成功率；本轮 ACT 不代表已确认“NCT”含义。
2. **固定上半身可重复执行**：PLA 试片/部件验证后逐侧联调，再验双臂；先确认遥操作、回到相同位置、热态漂移、停止行为与采集时间线。
3. **简单任务闭环**：从已称重的轻物抓放、分类、布角移动开始，以实测结果确定负载和动作范围；采集本机示范，核对预训练模型适配或训练/微调条件，记录成功率、时间、干预和失败。
4. **扩展能力**：基础任务稳定后再测双臂协作和简单折叠；移动底盘、长时间连续家务及原版负载指标留待后续验证。

加载权重、输出动作、实机完成任务分别验收。保持电机与轴线有助于接口复用，但打印件的柔性、相机布置和关节标定改变仍可能需要重新标定与本机数据适配。结构状态稳定后再进入既有正式研究协议。

## 研究问题与边界

同一任务、策略和平台下，比较抽象动作噪声与有物理/时序依据的真机故障干预。候选故障是 CAN 丢帧、指令延迟/抖动、力矩受限、摩擦增大；首轮只选一种。具体干预位置、可实现性和实际影响需要验证，不把所有候选变成已承诺实验。

原 [AMR F01](https://github.com/Jeffaaay/amr-faultbench) 不再是个人研究主线；保留故障目录、冻结评估器、隐藏测试及实验前写预测等方法。它的 MCU 恢复代码不能直接视为 OpenArm 策略评估代码，是否收尾为技术报告待定。公司 AMR 工程与原 P2/P3 的安排不因本次研究更新自动取消。

默认建议先用简单抓放，布角操作作为候选扩展；任务与 ACT / Diffusion Policy / VLA 在 M0/M2 结合可运行性确定，不承诺现有 GPU 可完成任意模型训练。首轮固定一个策略可检验预测问题；只有增加足够策略后才能讨论策略排名的普遍性。

重新考虑方向的依据仍是：完整文献检索发现具体问题已被回答，或单臂基准的真实失败证据指向其他问题。文献线索和另一位 AI 的检索摘要不等于新颖性已证实。实验定义见 [BASELINES.md](BASELINES.md#fault-injection-protocol)。

### 最近一周的执行队列

- **AI／M0**：核对最接近原文，整理“注入位置—机制—平台—指标—未覆盖范围”；补齐预测定义、对照和数据划分草案。预留 2–3 个投入工作日作首轮核查，不等于承诺完成穷尽检索。
- **用户／M1**：盘点实际主臂电机及修订、结构件、线束/配电缺项；核对 Mini 首件及主臂接口试片；按材料评估推进 J6_A/B/C 台架样件，再决定后续结构打印。
- **AI＋用户／M1**：根据实际驱动确定日志字段、时钟与采集接口，先离线审查一段示例数据；未接硬件时不记成遥操作通过。
- **共同检查**：用实物盘点与首轮联调结果更新 M1 预计完成时间。M2 之后的周计划按实际训练、复位和单次试验耗时估算，不沿用旧 AMR 的十月日程。
- **暂不开展**：为凑结果扩大故障种类、混入恢复算法改动、未经结构/接口验证部署 folding_final；把材料筛查或外观预览写成已完成实机实验。

M0 和 M1 可并行；M3 的离线设计也可提前，但正式实机故障比较须在可运行平台和冻结无故障基准之后。每次里程碑推进在此表填写证据链接、日期和版本；未通过项仍标未完成。

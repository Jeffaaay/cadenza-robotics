# Cadenza Robotics

基于 OpenArm 的机器人系统工程与操作学习研究项目。用户因预算决定第一阶段先做：**一条桌面 OpenArm＋夹爪，自行组装，完成遥操作抓放与布角操作。** 先建立可测量的单臂基准，再改进控制或学习方法；第二条臂与完整叠衣留待后续评估。

当前阶段：资料与搭建规划。已核对两个邮箱和部分任务历史，找到 RTX 4060 Ti 16GB 台式机、Jetson J4012、P1S、D405、CANable 和开发板的订单/送达证据，详见 [设备盘点](BUILD.md)。设备当前可调拨状态、OpenArm 本体、整个平台预算与桌面布局仍待确认，没有本项目的实机性能结果。

## 已确定的范围

- 首版一条 OpenArm（7 个臂关节＋1 个夹爪驱动），暂按右臂核价，制造前再核布局与匹配版本。一条 Mini 为示教输入候选，需要 8 个小舵机；已有 12 个先验证复用，单臂 Mini 软件接口尚待适配。
- 复用已有电脑、Jetson 和 P1S。相机先评估 D405 的可用性和视野；第二条臂、第二条 Mini、参考三相机、加长件和较大指垫暂不列为首轮购买要求。
- 用户已确认自行装配：购买电机、标准件和所需加工件，指定打印件用已有 P1S 制作，再按匹配教程逐步组装。预装整机报价只作成本对照，不计当前采购。不能把全部主臂承力件默认替换成家用塑料打印件。先做基础验证，再在叠衣复现前核对作者加长件、夹爪及相机配置。
- OpenArm 2.0.0 是本地 CAD/BOM 对照资料，需按所选侧与供货修订匹配。它是否等同于叠衣作者的基体，留在未来复现阶段核实，不再成为单臂基础试验的前置要求。
- 先建立参考配置的基准，再开发自己的非承力、可拆卸外壳。安装外壳后重新测量重量、温升、运动范围和跟踪误差。
- 五指手、指尖改造与钢琴演奏保留为未来方向，目前选型和制作暂停。此前人民币 3,000–7,000 元是单只灵巧手的零件预算，不是 OpenArm 总预算。
- 论文目标建立在可复现的测量与明确改进上。平台复刻、换名字或换壳是工程成果，本身不代表已形成论文贡献。

## 工作路线

| 阶段 | 要完成的事 | 完成的依据 | 当前状态 |
|---|---|---|---|
| 0 单臂报价与布局 | 核对一侧结构、8 个大臂电机、单 Mini 和已有设备 | 匹配版本的零件报价、供电固定方案与单臂空间检查 | 结构加工及总预算待核，尚不采购 |
| 1 单臂台架 | 装配、标定、夹爪与基础运动 | 状态日志、限位、跟踪、停止与恢复行为已验证 | 未开始实机验证 |
| 2 单臂示教 | 抓放固定物体、夹布角、抬起、拖动到标记区域；录制状态、动作与可用视角 | 任务可重复，Mini 映射与数据同步正确 | 未执行 |
| 3 单臂自主与改进 | 先选一个已能示教的任务，建立规划/学习基准，再根据失败改进 | 独立试验、原基准、消融与相同数据/干预预算 | 算法待任务和失败确定 |
| 后续 双臂叠衣 | 预算与单臂效果支持后，再增加第二条臂及参考配置 | 重新核对双臂接口、视角、工作区和公开策略 | 暂缓，不计首轮采购 |
| 基准后 外壳 | 完成可拆外壳，复测同一任务 | 质量、干涉、散热、视野和维护记录 | 未设计制造 |

先让参考配置可运行，再改变外观；安装后的性能与同一硬件的裸机配置比较。算法研究不依赖先完成外壳。

下一项具体工作是取得匹配版本的单臂机械零件包/加工报价，并验证现有小舵机、D405 和 CANable 的复用条件。8 个主臂电机的混合网站标价合计 $1,731，不是美国现货或含税到手价；其他零件及税运仍须核价，不把早先 $2,190–2,830 的粗估当成成交预算。采购表第三页已列美国现货、中国直寄、国内集货转运的同范围询价与到手成本计算，报价回复和目的地州/ZIP 尚待补齐。尚不下单或开印。

单臂阶段使用本地任务和示范建立基准。公开 folding_final 是双臂 16 维动作、三视角策略，不能直接删掉半边动作或相机就当作单臂模型；其接口审查保留供未来双臂扩展使用。

直接参考的技术报告、图片和视频集中在[Unfolding Robotics 阅读笔记](https://github.com/Jeffaaay/robotics-research-notes/tree/main/unfolding-robotics)。该报告是作者公开的工程实验，不标成已确认同行评审论文。Sunday Memo 作为完整家用系统的对照，不作为 OpenArm 的同款硬件或可直接部署的软件。
